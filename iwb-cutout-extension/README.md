# IWB 鲜艺抠图节点 - 浏览器插件

## 功能

在 **生图工作台** (iwb.maqiart.eu.org) 画布中，为每个图片节点添加四个快捷按钮：

1. **✂️ 鲜艺AI抠图**：自动调用本地鲜艺抠图软件去除图片背景，结果作为新节点插入画布或替换原图
2. **🔲 白底大图**：把节点图片（通常为透明图）转成白底（或透明底）大图（默认 800×800，内容占 85% 居中），适合电商主图等场景
3. **🖼️ 图片编辑器**：图层化编辑（图层、画笔、裁剪、标注），编辑后可选新建节点或覆盖原图
4. **压 图片压缩**：把节点图片按配置宽度（默认 1024px）等比缩放并转成 JPEG（默认质量 80%），完成后直接替换原图

空图片节点上工具条只显示 **空白画布** 按钮：按预设尺寸（1K，多种比例）创建空白图并自动打开编辑器，用于插图/标注。

## 工作流程

```
画布中的图片节点 → [抠图按钮] → 读取图片 → 鲜艺抠图API (localhost:30092) → 返回透明背景图 → 注入画布
                    [白底按钮] → 读取图片 → canvas 本地处理 → 白底/透明底大图 → 注入画布
                    [压缩按钮] → 读取图片 → canvas 缩放到目标宽度 → JPEG → 替换原图
                    [编辑按钮] → 读取图片 → 弹出编辑器 → 图层编辑/裁剪/标注 → 合并图层 → 新建或覆盖
```

白底、压缩和编辑器处理完全在浏览器本地用 canvas 完成，无需调用外部 API。

## 前置条件

1. **安装鲜艺AI抠图** - 从 [kt.94xy.com](http://kt.94xy.com/) 下载安装
2. **开启鲜艺抠图的 API 服务** - 软件设置中开启「Scheme & API 调用」
3. 确保鲜艺抠图正在运行（系统托盘有图标）

## 安装步骤

> 扩展加载的是构建产物：`manifest.json` 的 service_worker / content_scripts 以及 `popup.html` 引用的都是 `dist/*.js`。
> **首次加载前请先在仓库根目录执行 `npm run build`**（见下方「开发」），否则 `iwb-cutout-extension/dist/` 不存在，扩展会加载失败。

1. 打开 Chrome / Edge 浏览器
2. 地址栏输入 `chrome://extensions` (Edge: `edge://extensions`)
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `iwb-cutout-extension` 文件夹
6. 访问 https://iwb.maqiart.eu.org/ 即可使用

## 开发

源码在仓库根目录的 `iwb-cutout-extension/src/`，esbuild 打包到 `iwb-cutout-extension/dist/`，扩展加载的始终是 `dist/`。

**前置**：Node.js ≥ 20；在仓库根目录执行 `npm install` 安装开发依赖（esbuild、eslint、vitest、playwright 等）。

| 命令 | 说明 |
|------|------|
| `npm run build` | esbuild 打包 `src/entries/*` → `iwb-cutout-extension/dist/` |
| `npm run watch` | 监听 `src/` 变动自动重建 |
| `npm run lint` | ESLint 静态检查 |
| `npm run test` | Vitest 单元测试 |
| `npm run test:e2e` | Playwright 端到端冒烟测试 |
| `npm run verify` | 依次执行 lint → test → build → test:e2e |

- **改源码，不要直接改 `dist/`**：`dist/` 是构建产物，手工改动会在下次 `npm run build` 时被覆盖。修改 `src/` 后必须重新 `npm run build`，再在 `chrome://extensions` 点扩展的「重新加载」才能生效。
- 加载目录始终是 `iwb-cutout-extension`（含 `manifest.json`、`styles.css`、`popup.html`、`icons/`、`dist/`）。
- **e2e 会额外生成 `build/e2e-ext/`**：构建脚本的 `--e2e` 模式（`node scripts/build.mjs --e2e`）把 `manifest.json` 的 content_scripts `matches` 与 `host_permissions` 放宽到 `http://localhost/*`、`http://127.0.0.1/*`，并拷贝 `popup.html`、`styles.css`、`icons/`、`dist/` 组装成独立的测试扩展目录，供 Playwright 在本地 fixture 页面上注入；`build/` 已在 `.gitignore` 中忽略。

## 使用方法

1. 在画布中创建一个「参考图」节点并上传图片
2. 选中该节点后，节点气泡栏上方会出现扩展的**独立悬浮工具条**（挂在 `document.body` 上，只跟随应用气泡栏的位置，不修改应用 DOM），从左到右四个按钮：
   - **绿色「压」**：图片压缩（目标宽度 / 质量见配置，默认 1024px / 80%），完成后**替换原图**
   - **橙色剪刀** ✂️：鲜艺抠图（去背景）
   - **蓝色方块** 🔲：白底大图（透明图 → 白底或透明底 800×800）
   - **紫色编辑** 🖼️：图片编辑器（图层 + 裁剪 + 标注）
3. 点击按钮 → 等待处理 → 结果自动插入画布
4. 默认创建新节点；可在插件弹窗中切换为「替换原图」模式（「压」按钮不受该选项影响，始终替换原图）
5. 开启「抠图后自动转白底」后，点剪刀会直接输出白底大图，跳过透明图
6. 图片节点没有图片时，工具条上是「空白画布」按钮：选预设尺寸创建空白图并直接进入编辑器

### 图片编辑器用法（v2.2.0 图层化架构）

点击紫色编辑按钮后弹出全屏编辑器。v2.2.0 重构为图层架构，每个元素独占一层，右侧有图层面板管理。

#### 工具栏

| 工具 | 说明 |
|------|------|
| ⬚ 选择 | **统一选择工具**：点击任意元素（位图/文字/矩形/箭头/钢笔形状）选中；拖拽移动；手柄调整大小；双击文字改内容；Delete 删除 |
| ✏️ 画笔 | 在**当前活动图层**上自由绘制；**硬度** 0~100（100=硬边，越低边缘越软）；**透明度** 5%~100%（一笔整体透明，笔划内不叠加变深）；粗细 1~300；圆形笔刷光标与大小精确匹配 |
| ▭ 矩形 | **图层化形状**：拖拽画矩形框；点边框选中；拖拽移动；拖 8 个手柄调整大小；Delete 删除；选中时点色板改色；「实心」开关切换填充 |
| ➤ 箭头 | **图层化形状**：拖拽画箭头（起点→终点）；点线条选中；拖拽移动；拖 2 个端点手柄调整方向/长度；Delete 删除 |
| ✒ 钢笔 | 点击连续节点绘制自定义路径；双击或 Enter 完成；选择后可整体移动、拖动顶点、删除和锁定 |
| T 文字 | **图层化文字**：点击空白输入新文字；点已有文字选中；拖拽移动；拖角缩放字号；双击改内容；Delete 删除；选中时点色板改色 |
| 🧽 橡皮 | **擦除当前活动图层**（位图层）：与画笔共用大小/硬度/透明度参数；软边羽化擦除，圆圈光标=粗细值；可撤销 |
| 💧 吸管 | **点击画布取色**（取样所有可见图层合成后的实际颜色）；悬停实时预览颜色与十六进制值；取色后自动切回上一工具 |
| ✋ 抓手 | **自由移动画布**：拖拽任意方向平移（小图也可移动）；等效于按住空格拖拽或鼠标中键拖拽 |
| ⬚ 裁剪 | 拖拽选区 → 画完后可 **8 个手柄微调大小** 或 **框内拖拽整体移动** → 确认裁剪 |
| ↶ 撤销 | 撤销上一步（Ctrl+Z），可一路撤回到原始状态 |
| ↷ 重做 | 重做（Ctrl+Shift+Z） |
| ⟲ 重置 | 清空所有标注（保留裁剪结果） |
| 🖼 复原 | **一键回到原始图片**，撤销所有标注与裁剪（有确认提示） |
| − / ＋ | 缩小 / 放大画布（10% ~ 1000%） |
| 适应 | 一键恢复适应窗口大小 |

#### 图层系统（v2.2.0 新增）

编辑器右侧有**图层面板**，统一管理所有图层（位图层 + 矢量对象层）：

- **图层列表**：按 z 序从上到下排列（上层在前），每个图层显示图标、名称、可见性开关、删除按钮，可拖拽图层项调整顺序
- **位图层**：
  - **原图层**（base）：打开图片时自动创建，作为底层
  - **画笔标注层**（draw）：默认活动层，画笔和橡皮在此层操作
  - **导入图层**：点图层面板顶部「+ 添加图片」按钮可导入外部图片作为新位图层；确认放置后仍可用「选择」工具移动、缩放，按住 Shift 可保持图片比例
   - **锁定控制**：每个图层右侧的锁图标可独立锁定/解锁；锁定后仍可选中查看，但禁止移动、缩放、绘制、擦除、改色、改文字和删除；原图层默认锁定
- **矢量对象层**：文字、矩形、箭头在内部以 textLayers/shapeLayers 数组管理，在图层面板中与位图层一起显示
- **图层操作**：
  - **切换活动层**：点击图层面板中的图层项，画笔/橡皮将作用于活动层
  - **可见性**：点击眼睛图标切换图层显隐（隐藏的图层不参与合成、导出、裁剪）
  - **删除**：点击删除按钮移除图层（原图层不可删除）
- **橡皮统一**：v2.2.0 将原来的两个橡皮（标注橡皮 + 图片橡皮）合并为一个，擦除目标 = 当前活动图层。切换活动层即可擦不同内容

#### 画笔与橡皮参数（v2.2.0 统一）

画笔和橡皮共用一套参数控制器，不再有独立的橡皮参数：

- **大小**：1~300（滑块 + 数值输入框双向同步），画笔粗细 = 橡皮擦除宽度
- **硬度**：0~100。100=硬边（清晰描边/清晰擦除边界）；降低后边缘渐变羽化，0=最软（径向渐变笔刷）
- **透明度**：5%~100%。画笔一笔整体按此透明度合成（同一笔内反复涂抹不叠加变深）；橡皮的透明度控制单次擦除强度
- 硬度+透明度可组合使用（软边半透明效果），可撤销

#### 其他功能

- **缩放**：滚轮以鼠标为中心缩放（放大方便精细标注，缩小后整图裁剪）；工具栏有百分比显示
- **平移**：三种方式任意方向自由移动画布——**✋ 抓手工具**拖拽 / 按住 **空格** + 左键拖拽 / **鼠标中键** 拖拽；画布跟随鼠标方向移动（抓手语义）；空格是临时修饰键，松开即恢复原工具，窗口失焦自动复位；不再限制居中或滚动范围，小图也能随意挪到任意位置；「适应」按钮一键回到居中
- **圆形笔刷光标**：画笔/橡皮悬停时显示与当前笔刷大小精确匹配的圆形光标（隐藏系统十字光标），调粗细/大小时圈实时跟随；任何尺寸都显示圆圈不回退十字标，笔刷极小时圈自动放大到最低可见尺寸（屏幕半径 2px）
- **颜色**：6 种预设色 + **自定义颜色**（预设色板旁的圆形取色器，点击打开系统取色器，实时生效）；选中文字/形状时改色会同步应用到选中元素
- **裁剪约束**（选裁剪工具后底部显示）：
  - **比例**：自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16 — 拖拽和手柄调整都保持比例
  - **尺寸**：输入宽×高（如 800×800）→ 点「应用」→ 裁剪框按比例约束，确认时自动缩放到指定尺寸；尺寸约束可勾选启用或取消
  - 实时显示当前裁剪框尺寸（如 `400×300 → 800×800` 表示将缩放到 800×800）
- **裁剪框**：一次只能绘制一个，画完后可拖 8 个手柄微调大小，或在框内拖拽整体移动定位（保持尺寸/比例不变）；想重新裁剪先点 ✗ 取消
- **选择工具**：不用切工具，一个工具调所有元素——
  - **选中**：点击任意文字/矩形/箭头/钢笔形状（文字在上层优先命中；实心矩形点内部也能选中）
  - **移动**：选中后直接拖拽
  - **调整**：文字拖 4 角改字号；矩形拖 8 手柄改大小；箭头拖 2 端点改方向长度
  - **旋转**：位图层、导入图片、形状与文字选中后，四个角外侧显示圆弧旋转手柄，拖拽即旋转（悬停变旋转光标），按住 **Shift** 按 15° 吸附；可撤销
  - **改内容**：双击文字重新编辑
  - **删除**：Delete / Backspace
  - **改色/实心**：选中后点色板改色；选中矩形时切「实心」开关即时生效
- **图层顺序**（矢量对象）：顶栏「图层」按钮组调整选中矢量元素的上下层关系——
  - **⤒ 置顶 / ⤓ 置底**：移到最上层 / 最下层（Ctrl+Shift+] / Ctrl+Shift+[）
  - **↑ 上移一层 / ↓ 下移一层**：与相邻元素交换位置（Ctrl+] / Ctrl+[）
  - 需先选中元素（任意工具下选中即可），按钮随选中态自动启用/禁用
- **底部按钮**：取消 / 新建节点 / 覆盖原图
- **快捷键**：Esc 不关闭编辑器，仅取消文字输入、钢笔预览或当前选择，Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Delete 删除选中的文字/形状，Ctrl+] / Ctrl+[ 上移/下移一层，Ctrl+Shift+] / Ctrl+Shift+[ 置顶/置底

## 配置选项

点击浏览器工具栏的插件图标打开设置弹窗：

| 选项 | 说明 | 默认 |
|------|------|------|
| API 地址 | 鲜艺抠图服务地址 | http://localhost:30092 |
| 自动裁剪 | 抠图后裁掉多余透明像素 | 开启 |
| 结果模式 | 创建新节点 / 替换原图 | 创建新节点 |
| 自动连接 | 新节点模式下自动连线 | 开启 |
| 自动转白底 | 抠图后直接生成白底大图 | 关闭 |
| 白底尺寸 | 白底画布边长 (px) | 800 |
| 内容占比 | 原图最长边占画布比例 (%) | 85 |
| 大图背景 (bgMode) | `white` 白底（填充白色） / `transparent` 透明底（保留透明通道） | white（白底） |
| 压缩宽度 (compressWidth) | 「压」按钮的目标宽度 (px)，高度按原图比例缩放 | 1024 |
| 压缩质量 (compressQuality) | 「压」按钮输出 JPEG 的质量 (%)，数值越高越清晰 | 80 |

> 白底规则：内容等比缩放至最长边 = 尺寸 × 占比，水平垂直居中，其余区域纯白；`bgMode=transparent` 时不填充白色，保留透明背景（尺寸与占比规则不变）。

### 文件结构

扩展目录（`chrome://extensions` 加载的就是它）：

```

├── manifest.json       # MV3 配置 (v3.0.0)；service_worker 与 content_scripts 指向 dist/*.js

├── styles.css          # 注入样式（含编辑器 + 图层面板样式）
├── src/                # 源码（改动这里）
│   ├── content.js      # 内容脚本：编排抠图/白底/压缩/编辑流程（宿主 DOM 一律走 host-adapter）
│   ├── editor/         # 图层化图片编辑器（v3.0.0 起由 11 个模块组成，共 4288 行）
│   │   ├── state.js    #   唯一状态所有者：S / ZOOM_* / runtime.el（叶子模块，不 import 编辑器内部模块）
│   │   ├── index.js    #   打开/关闭/导出 + window.__iwbEditor 对外接口
│   │   ├── dom.js      #   遮罩层 DOM 构建

│   │   ├── placement.js#   导入图片放置
│   │   ├── tools.js    #   画笔/橡皮/吸管/合成画布
│   │   ├── crop.js     #   裁剪
│   │   ├── objects.js  #   文字/形状/钢笔/选择与手柄
│   │   └── events.js   #   鼠标/键盘事件、UI 更新
│   ├── background.js   # 后台服务：调用鲜艺抠图 HTTP API
│   ├── popup.js        # 弹窗逻辑（配置校验、「自检」、「最近一次错误」）
│   ├── shared/         # 跨文件共享模块

│   └── entries/        # esbuild 打包入口
│       ├── content.js  # 先加载 editor/index.js，再加载 content.js
│       ├── background.js
│       └── popup.js
├── dist/               # 构建产物（npm run build 生成；扩展实际加载）
├── icons/              # 插件图标
└── gen_icon.py         # 图标生成脚本
```

### 图层架构（v2.2.0）

编辑器采用多 canvas 叠加架构：

- **位图层**：每个位图层（原图、画笔标注、导入图片）是一个独立的 `<canvas>` 元素，通过 CSS `position: absolute` 叠加在 canvas-stack 容器中，z 序由图层顺序决定
- **矢量层**：文字和形状共享一个 `textCanvas`，通过 `renderObjects()` 统一渲染，每个对象有独立的 `globalAlpha` 控制透明度
- **活动层**：画笔和橡皮始终作用于 `activeLayerId` 指定的位图层，切换活动层即可在不同图层上绘制/擦除
- **合成画布**：导出/吸管/裁剪时，通过 `getCompositeCanvas()` 将所有可见位图层 + 矢量层合成到一张临时画布上
- **历史快照**：`snapshotState()` 捕获所有位图层的 ImageData + 图层顺序元数据 + 矢量对象状态，`restoreState()` 完整恢复

### 鲜艺抠图 API

- **HTTP**: `POST http://localhost:30092/rmbg?crop=true|false`
  - 请求体: 二进制图片数据
  - 返回体: 二进制图片数据 (PNG 透明背景)
- **WebSocket**: `ws://localhost:30092/ws`

### 注入机制

插件通过 **file input + DataTransfer** 方式注入抠图结果，走应用自身的 `onChange` 处理器，确保 React 状态正确更新：

1. 读取 `<img>` 的 src（base64 或 URL）
2. 发送到 background.js → 调用鲜艺抠图 API
3. 将结果转为 File 对象
4. 通过 `DataTransfer` 设置到 file input
5. dispatch change 事件 → 应用自动处理

## 故障排查

- **按钮不出现**：确保页面已完全加载，刷新页面；工具条只在带图片的节点（参考图/输出）的气泡栏附近出现
- **改了代码没生效**：源码改动后必须 `npm run build` 更新 `dist/`，并在 `chrome://extensions` 重新加载扩展；直接改 `dist/` 会被下次构建覆盖
- **加载扩展报错找不到 dist/*.js**：先在仓库根目录执行 `npm run build` 生成 `iwb-cutout-extension/dist/`
- **API 连接失败**：确保鲜艺抠图正在运行，且 API 端口 30092 未被占用；设置页“测试连接”只判断服务是否可达，HTTP 405/500 仍表示端口有响应，真正抠图错误会显示 API 返回信息
- **抠图结果未出现**：尝试切换为「替换原图」模式，或手动 Ctrl+V 粘贴；若本地服务返回空响应，请检查鲜艺软件的模型/API 是否已完成启动
- **图片读取失败**：插件会先在页面上下文把图片转换为 base64；若页面受 CORS/鉴权限制，会自动回退到扩展后台按图片 URL 下载；若后台也无法下载，请先让图片完整加载或下载后重新上传
- **CORS 错误**：确保插件已正确加载，host_permissions 包含 localhost:30092
